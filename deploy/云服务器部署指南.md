# Planner App 云服务器部署指南

本指南面向云服务器（以 Ubuntu 22.04+ 为例），使用 Docker Compose 部署后端 + PostgreSQL，并通过 Nginx 提供 Web 静态与 `/api` 反向代理。  
默认避开 `80/8000` 端口，使用 `8080/8443` 对外访问，API 仅在本机 `127.0.0.1:18000` 暴露。  
当前不绑定域名，优先通过公网 IP 访问。

## 0. 变量与约定
- 项目目录：`/home/admin/planner-app`（可按需调整）
- 外网端口：`8080`（HTTP）、`8443`（HTTPS）
- API 端口：`127.0.0.1:18000`
- 域名：暂不配置（可后续补）

## 1. 云服务器与安全组
1. 系统：Ubuntu 22.04+  
2. 安全组入方向放行：`22`、`8080`、`8443`  
3. 不开放：`18000`、`5432`（保持内网/本机访问）

## 2. 域名解析（可选）
当前阶段先不绑定域名，可跳过。后续需要域名时再添加 A 记录指向公网 IP。

## 3. 服务器初始化
```bash
sudo apt update
sudo apt install -y docker.io docker-compose nginx
sudo systemctl enable --now docker nginx
```

## 4. 上传代码到服务器
上传（本地执行）：
```bash
scp -r ./planner-app admin@SERVER_IP:/home/admin/planner-app
```

## 5. 配置生产环境变量
```bash
cd /home/admin/planner-app
cp deploy/.env.prod.example deploy/.env.prod
```
编辑 `deploy/.env.prod`，至少设置：
- `SECRET_KEY`
- 数据库账号/密码

## 6. 启动后端与数据库
```bash
cd /home/admin/planner-app
docker compose -f deploy/docker-compose.yml up -d --build
```
验证：
```bash
curl http://127.0.0.1:18000/docs
```

## 7. 构建并部署 Web 前端
```bash
cd /home/admin/planner-app/frontend/web
npm install
npm run build
sudo rm -rf /var/www/planner-web
sudo cp -r /home/admin/planner-app/frontend/web/dist /var/www/planner-web
```

## 8. HTTPS 证书（可选）
当前不绑定域名可暂不配置证书，先用 `http://IP:8080` 访问。  
若后续使用阿里云证书服务，步骤如下：
1. 申请并下载 Nginx 证书包  
2. 上传到服务器并放置：
```bash
sudo mkdir -p /etc/letsencrypt/live/myai.yun
sudo cp /path/to/fullchain.pem /etc/letsencrypt/live/myai.yun/fullchain.pem
sudo cp /path/to/privkey.pem /etc/letsencrypt/live/myai.yun/privkey.pem
sudo chmod 600 /etc/letsencrypt/live/myai.yun/privkey.pem
```

## 9. 配置 Nginx
```bash
sudo cp /home/admin/planner-app/deploy/nginx.conf /etc/nginx/conf.d/planner.conf
sudo nginx -t && sudo systemctl reload nginx
```

## 10. 访问验证
- Web：`http://SERVER_IP:8080`
- HTTPS：`https://SERVER_IP:8443`（仅当已配置证书）
- API：`http://SERVER_IP:8080/api/docs`

## 11. 常用排查
- API 日志：
```bash
docker compose -f /home/admin/planner-app/deploy/docker-compose.yml logs -f api
```
- Nginx 日志：`/var/log/nginx/error.log`

## 12. 更新流程（本地上传 + Compose 重启）
本地上传：
```bash
scp -r ./planner-app admin@SERVER_IP:/home/admin/planner-app
```
服务器重启：
```bash
cd /home/admin/planner-app
docker compose -f deploy/docker-compose.yml up -d --build
```
如有 Web 更新：
```bash
cd /home/admin/planner-app/frontend/web
npm install
npm run build
sudo rm -rf /var/www/planner-web
sudo cp -r /home/admin/planner-app/frontend/web/dist /var/www/planner-web
sudo systemctl reload nginx
```

## 13. 生产安全建议
- 生产环境禁用默认管理员用户：`backend/app/main.py` 的 `_ensure_default_admin_user`
- 只开放必要端口
- 定期备份数据库
